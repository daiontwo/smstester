# SMS Tester

Минимальный тестовый Android-проект.

Функции:
- ручная отправка SMS;
- циклическая отправка на один номер;
- настраиваемый интервал (минимум 10 секунд);
- приём входящих SMS;
- ручной ответ последнему отправителю;
- автоответ, если входящий текст содержит заданное слово.

## Запуск
1. Открыть папку `SmsTester` в Android Studio.
2. Дождаться Gradle Sync.
3. Подключить Android-телефон с SIM-картой.
4. Run → app.
5. Разрешить отправку и получение SMS.

Важно: эта тестовая версия не использует foreground service, поэтому цикл предназначен для работы при открытом приложении.
